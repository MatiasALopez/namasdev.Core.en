# namasdev.Core.en

Foundational .NET utilities: domain entities with audit-trail support, validation, culture-aware formatting (dates, numbers, currency), dynamic LINQ, and IO helpers. This is the base package the other `namasdev.*.en` libraries depend on.

## Install

```
dotnet add package namasdev.Core.en --prerelease
```

## Target frameworks

`net48`, `net9.0`
